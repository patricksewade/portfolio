## 1. Synthèse de la Release v1.1.0

La version **v1.1.0** concrétise la refonte intégrale de l'ancien code procédural vers une architecture **Orientée Objet (POO) pure et MVC stricte** en PHP 8.3, tout en intégrant des fonctionnalités dynamiques complètes et une interface sombre soignée.

### Principales réalisations :
- **Architecture MVC Maison** :
  - Namespace `App\` sous standard **PSR-4** avec Composer.
  - Noyau HTTP personnalisé (`Request`, `Response`, `Router`, `ViewRenderer`, `EnvLoader`).
  - Découplage complet Controllers / Repositories / Entities / Services.
- **Gestion Dynamique des Projets (CRUD)** :
  - Administration complète des projets (création, édition, suppression).
  - Gestion sécurisée des uploads d'images via `samayo/bulletproof` (validation MIME, limite 2 Mo).
  - Nettoyage physique automatique des images orphelines via `unlink()` lors du remplacement ou de la suppression.
  - Pattern Post-Redirect-Get (PRG) et notifications éphémères (Flash messages en session).
- **Sécurité Renforcée** :
  - Protection CSRF systématique sur toutes les requêtes d'action unitaire et formulaires sensibles via `SecurityService`.
  - Échappement XSS centralisé (`SecurityService::escape()`).
  - Hachage de mot de passe sécurisé et isolation du hash à la sérialisation (`Admin::__serialize()`).
  - Cookies de session HTTPOnly, Secure et SameSite=Strict.
- **UI/UX & Expérience Utilisateur** :
  - Thème sombre TailwindCSS "Premium".
  - En-tête enrichi (liens sociaux, CTA téléchargement CV).
  - Pied de page avec bouton interactif "Back to Top" (Vanilla JS).
  - Compteurs de projets et statistiques dynamiques synchronisés avec la base de données.
  - Formulaires accessibles (`aria-required`, contrastes WCAG validés).
- **Messagerie & Contact** :
  - Service d'expédition d'emails `SmtpMailer` OOP (stream socket SMTP) avec support Mailtrap (local) et Brevo (production).

## 2. État du Répertoire & Composants à cette Version

- `src/Config/` : `Database.php`, `EnvLoader.php`
- `src/Controller/` : `HomeController.php`, `AdminController.php`, `AdminProjectController.php`, `LegalController.php`
- `src/Core/` : `Router.php`, `ViewRenderer.php`
- `src/Http/` : `Request.php`, `Response.php`
- `src/Model/` : `Admin.php`, `Project.php`, `Message.php`
- `src/Repository/` : `AdminRepository.php`, `ProjectRepository.php`, `MessageRepository.php`
- `src/Service/` : `SecurityService.php`, `SmtpMailer.php`
- `src/helpers.php` : Fonctions polyfills pour les vues (`e()`, `is_admin()`, `csrf_token()`)
- `templates/` : Vues modulaires PHP (`home.php`, `legal.php`, `admin/`, etc.)
- `public/` : `index.php`, `.htaccess`, assets et uploads (`public/uploads/projects/`)
